# Portofolio Graphic Designer (Next.js + Tailwind + Framer Motion)

Jalankan lokal:
  npm install
  npm run dev        -> http://localhost:3000

Admin: klik titik terakhir di footer ("© 2026 Nama.") atau Ctrl+Shift+A, lalu masukkan password.
Agar data (karya, kategori, like, pesan masuk) tersimpan online untuk semua pengunjung:
lihat .env.example dan supabase/setup.sql.
